# Security policy

If you think you've found a security vulnerability in anything Infinite Device
Labs maintains, please report it privately rather than in a public issue.

## How to report

- **On GitHub:** where a repository has private vulnerability reporting
  enabled, use **Security → Report a vulnerability** on that repository.
- **By email:** [security@infinitedevice.xyz](mailto:security@infinitedevice.xyz).
  This is the same contact our
  [`security.txt`](https://infinitedevice.xyz/.well-known/security.txt) lists.

Please include what's affected (repository, version or commit, URL), how to
reproduce it, and what impact you expect. We read reports in English.

## What to expect

We'll acknowledge your report, keep you updated while we investigate, and tell
you when it's fixed. We'll credit you in any advisory if you'd like to be
credited.

Please give us a reasonable chance to fix the issue before you disclose it
publicly, and don't access, change or delete data that isn't yours while
investigating.

## Scope

This policy covers the repositories in the
[Infinite-Device-Labs](https://github.com/Infinite-Device-Labs) organization
and the services they run. A repository's own `SECURITY.md`, where it has one,
takes precedence over this file.
